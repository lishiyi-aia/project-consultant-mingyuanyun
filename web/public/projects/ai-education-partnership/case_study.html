PROJECT CONSULTANT PORTFOLIO / 01

AI教育产品客户合作与试点推进

围绕高校及东南亚AI教育产品合作，协助确认需求、准备演示与试点材料，跟进协议、待办及使用反馈。

商务助理实习生（客户项目支持方向）

工作主线

确认需求 → 准备方案与演示 → 协议及交接 → 跟进使用问题 → 周度汇总 → 更新清单与后续安排

01 / PROCESS

需求确认

通过邮件及会议梳理高校客户需求、试用安排与合作条件，建立客户台账，记录沟通要点和待办事项。先明确客户要解决的问题，再为方案讨论准备产品信息。

02 / PROCESS

方案与演示准备

根据已确认的需求准备产品介绍及合作方案；会前确认参会人员、演示账号与培训材料，支持产品演示、试点及合作会议。将客户关注点带入演示与讨论。

03 / PROCESS

协议核对与交接

核对合作协议的主体信息、服务范围、双方分工及付款节点，汇总修改意见并跟进版本确认；对接业务与财务完成审批、盖章及归档，支持协议签署与项目交接。

04 / PROCESS

待办跟踪

会后整理纪要，明确事项负责人及完成时间；协调产品团队处理使用问题，每周汇总进展和未完成事项，使沟通结果进入后续行动。

05 / PROCESS

AI与流程沉淀

利用AI梳理客户跟进和资料准备中的重复步骤，经人工核对后整理为SOP、检查清单与常用模板。将反复出现的资料要求和问题纳入后续准备。

结果与复盘

将客户沟通、演示试用、协议核对与项目交接串联起来，通过会议纪要和每周进展汇总跟进待办，并沉淀SOP、检查清单与常用模板，支持后续项目按统一流程推进。
